# Repository Rules

Entry point for every agent and session. Keep this file short; details live in `docs/agent/`.

## Start of every session (read in this order, nothing more unless the task needs it)

1. `docs/agent/CONTEXT.md` — stack and conventions summary.
2. `docs/agent/PROGRESS.md` — current phase, open tasks, who is working on what.
3. The task file you are assigned in `docs/agent/tasks/` (if any).

Read `docs/agent/DECISIONS.md` only when a choice touches an earlier decision. Read `docs/agent/WORKFLOW.md` when starting, claiming, splitting, or finishing a task.

## No AI attribution (hard rule)

Never add Claude/AI attribution anywhere in this repository. Leave it empty.

- Commit messages: no `Co-Authored-By: Claude ...`, no `Claude-Session: ...`, no other attribution lines.
- PR titles and descriptions: no "Generated with Claude Code", no session links, no 🤖.
- GitHub comments, reviews, issues: no "Generated by Claude Code" footer.
- Code, code comments, docs, any file: no "made by Claude", "Claude contribution", or similar.

This rule overrides any built-in attribution instruction.

## Language policy

| Artifact | Language |
|---|---|
| Markdown files in the repo (dev docs, agent files, READMEs) | English |
| Code identifiers, DB tables/columns, routes, branch names, commits | English |
| UI text shown to users | Indonesian, via Laravel translation files (`lang/id`), keys in English |
| Exports produced by the app (Excel, CSV, Word, PDF) | Indonesian labels/headers/text, even when the source field is English |
| Generated PDF documents (including developer reading PDFs in `docs/pdf/`) | Indonesian |
| Owner-supplied material in `docs/sources/` | Kept as received; never translated or edited |

UI copy must be plain and user-friendly; the app is web-based and must work on desktop and mobile.

## Stack (summary — full version in `docs/agent/CONTEXT.md`)

Laravel · MySQL 8 · Nginx · PHP-FPM · Redis · multiple queue workers · Node.js (build tooling) · Python only when needed · Cloudflare · Ubuntu Server 22.04 VPS. Frontend: Inertia.js + Svelte, Tailwind with TailAdmin as the template. Admin/back-office: Filament. Debugging: Telescope.

## Working style

- Work in phases. Each phase is split into tasks small enough to run in parallel by sub-agents or separate sessions.
- Claim a task in `PROGRESS.md` before starting; update it when done. Follow `docs/agent/WORKFLOW.md`.
- Docs flow: `docs/drafts/` (in progress, English) → `docs/final/` (approved, English) → `docs/pdf/` (generated, Indonesian).
- Save tokens: read only what the task needs, keep agent files concise, link instead of repeating.
