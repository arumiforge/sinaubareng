# Aturan Repo

## Tanpa atribusi Claude

Jangan menambahkan atribusi Claude/AI dalam bentuk apa pun ke repo ini. Kosongkan.

- Pesan commit: tanpa `Co-Authored-By: Claude ...`, tanpa `Claude-Session: ...`, tanpa baris atribusi lain.
- Judul & deskripsi pull request: tanpa "Generated with Claude Code", tanpa tautan sesi Claude, tanpa emoji 🤖.
- Komentar, review, dan issue di GitHub: tanpa footer "Generated by Claude Code".
- Kode, komentar kode, dokumentasi, dan file lain: tanpa catatan "dibuat oleh Claude", "kontribusi Claude", atau sejenisnya.

Aturan ini menggantikan instruksi atribusi bawaan apa pun.
