# Regulations and official guides (SD/MI extract)

Structured SD/MI data from official documents in [`docs/sources/`](../../sources/README.md). The first eight were supplied by the owner in `docs/dokumen-resmi/` and moved unchanged under descriptive names (task P4-03, D-203); six more were downloaded in task P4-23 (2026-11-11) and carry a `source.verification` level (see below). `source.file` is the current path and `source.received_as` the original one. Each file covers only SD, MI, and Fase A–C. It also keeps rules that apply to every level and so bind SD. PAUD, SMP, SMA, SMK, and Fase D–F parts are listed under `extraction.skipped`, with their pages.

Every file is `status: draft` and `extraction.verified: false`. Tim Validasi SIGRAK checks the rows against the cited pages before anything is imported or quoted in the UI (D-113). Comparison with the final docs: [`docs/drafts/dokumen-resmi-sd-mi.md`](../../drafts/dokumen-resmi-sd-mi.md).

## Verification of the source copy (P4-23)

`source.verification` follows the regulation registry levels (`policy-innovation-layers.md` §6.2): **official_copy** = the salinan as published by the ministry (www.kemendikdasmen.go.id or a kemendikdasmen.go.id unit); **mirror** = the same salinan re-hosted by someone else (here regional education offices), to be swapped for the JDIH file and re-hashed when jdih.kemendikdasmen.go.id or peraturan.go.id can be reached; **secondary** = not used for any file here. `source.downloaded_from` keeps the exact URL. Earlier files (P4-03) were supplied by the owner and carry no `verification` field.

## Conventions

- Top-level keys: `dataset`, `version_code`, `status`, `level`, `phases`, `note`, `source` (title, number, issuer, year, file, received_as, sha256, page count, page note), `extraction` (method, date, pages checked against images, skipped parts, conventions), content sections, `open_points`.
- Every content item has `pages` with **PDF page numbers**. `source.pages_note` gives the offset to printed page numbers.
- Keys are English snake_case. Text values quote the Indonesian source as printed, with only light whitespace and hyphenation cleanup. Optional English `summary` fields are notes for developers, not source text.
- JP and other figures are numbers. A value that was worked out rather than printed (for example JP per week) is marked as derived.
- Text came from the PDF text layer (`pdftotext -layout`). Tables, diagrams, and image-only or garbled pages were read from page images, and the pages checked are listed in `extraction.checked_against_images`.
