# P4-12 — Teacher supervision instruments for SD/MI

- **Phase:** P4
- **Status:** done
- **Owner:** p4/p4-04-administration-features
- **Depends on:** D-217 (supervisi akademik in scope), D-221 (owner samples as starting formats)
- **Can run in parallel with:** P4-05…P4-11

## Goal

Map every instrument a principal uses to supervise SD/MI teachers (guru kelas, guru mapel, wali kelas) and write a first draft of each, aligned with the 2025–2026 rules (Pembelajaran Mendalam, RPM, Standar Proses 1/2026, Permendikdasmen 6/2026), starting from the owner's sample. Supervision of the principal or the school by the pengawas is out of scope.
